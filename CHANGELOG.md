# Changelog

All notable changes to **rai.gk** are documented in this file.

## v0.5.0

- `tech-catalog.jsonl`: generated by `main.py` from every technology in the data, with its `source` (`npm`, `python`, `docker`) and editable `category`, `reason`, `importance`.
- Append-only sync: new technologies go at the end after three empty lines, existing annotations are never overwritten, no duplicates.
- Output files renamed in kebab-case: `reports-full.jsonl`, `reports-public.jsonl`, `tech-catalog.jsonl`.
- Record building moved to `scripts/utils_records.py`.

## v0.4.0

- Reports split in two: `reports-full.jsonl` (private) and `reports-public.jsonl` (sanitized, whitelist-based, safe for the front-end).
- `reports.jsonl` renamed `reports-full.jsonl`.
- Records sorted chronologically; the public report uses a stable `index` instead of the SHA.
- Public dates reduced to `YYYY-MM-DD`, Docker reduced to service names, private npm scopes filterable.
- Documented the front-end workflow and the security model.

## v0.3.0

- Commit history exported as JSONL instead of Markdown (`gitlab-commits-to-json.js`), branch stored in each line.
- Records written as JSONL instead of one Markdown report per archive.
- `all_commits.jsonl`: every commit, deduplicated by SHA, oldest first.
- Scripts moved to `scripts/`; `merge.py` removed.
